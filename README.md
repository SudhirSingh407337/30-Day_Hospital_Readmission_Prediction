## Dataset and Study Source

This project uses the Diabetes 130-US hospitals dataset from 
[Kaggle]([https://www.kaggle.com/datasets/brandao/diabetes](https://www.kaggle.com/datasets/brandao/diabetes)), 
originally associated with the study by Beata Strack et al.

- Dataset source: [https://www.kaggle.com/datasets/brandao/diabetes](https://www.kaggle.com/datasets/brandao/diabetes)
- Original study: [https://pubmed.ncbi.nlm.nih.gov/22287225/](https://onlinelibrary.wiley.com/doi/10.1155/2014/781670)
